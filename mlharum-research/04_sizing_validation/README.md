# Step 4 — Size Estimation Validation

## Goal
Quantify the accuracy of the hand-scale sizing pipeline against physical caliper measurements.
This produces the paper's Table 3 and Figure 4 (Bland-Altman plot).

---

## Workflow

```bash
cd mlharum-research

# 1. Run the sizing pipeline on all validation images
python 04_sizing_validation/run_pipeline.py \
    --images ../01_data_collection/validation_images/ \
    --ground_truth ../01_data_collection/ground_truth_template.csv \
    --output 04_sizing_validation/results/pipeline_output.csv

# 2. Compute error metrics
python 04_sizing_validation/compute_metrics.py \
    --input 04_sizing_validation/results/pipeline_output.csv \
    --output 04_sizing_validation/results/
```

---

## Metrics to report (Table 3)

| Metric | Formula | Target |
|---|---|---|
| MAE | mean(|estimated − caliper|) | < 0.5 cm |
| RMSE | sqrt(mean((estimated − caliper)²)) | < 0.8 cm |
| MAPE | mean(|estimated − caliper| / caliper) × 100 | < 15% |
| r² | Pearson correlation² | > 0.90 |
| Bias | mean(estimated − caliper) | near 0 |

Report metrics **overall** and **per growth stage**.

---

## Key figures (Figure 4 in paper)

1. **Scatter plot** — estimated vs caliper (ideal = diagonal line)
2. **Bland-Altman plot** — agreement between methods
3. **Error by growth stage** — boxplot of (estimated − caliper) per stage

All generated by `compute_metrics.py`.

---

## Knuckle width sensitivity analysis

The sizing formula is:
```
size_cm = (bbox_height_px / knuckle_width_px) × AVG_KNUCKLE_WIDTH_CM
```

`AVG_KNUCKLE_WIDTH_CM` is fixed at 1.8 cm by default.
`run_pipeline.py` can test multiple values (1.6, 1.7, 1.8, 1.9, 2.0 cm) to show
sensitivity — include this as a supplementary table.
